# Colimator

Сборка вертикальных explainer-роликов из длинных видео: говорящая голова,
субтитры, анимированная графика на «бесконечном холсте», движение камеры и
переходы. Стиль снят с референсного ролика Anthropic — разбор в
`docs/reference-breakdown.md`.

## Установка

Нужны Python 3.11+ и ffmpeg.

```bash
git clone <репозиторий> && cd Colimator
pip install -r requirements.txt
playwright install chromium
```

Дальше — одна команда, которая проверит всё сразу:

```bash
python scripts/check_env.py
```

Она скажет, чего не хватает. Чаще всего это ffmpeg: playwright ставит свою
копию, но она не попадает в PATH и нам не годится. Ставить отдельно —
macOS `brew install ffmpeg`, Ubuntu `apt install ffmpeg`, Windows
`winget install Gyan.FFmpeg` и потом перезапустить терминал.

## Что умеет

| Модуль | Что делает |
|---|---|
| `colimator/captions.py` | SRT/VTT → строки по 3–5 слов в ритме референса → `.ass` |
| `colimator/canvas.py` | сцена на HTML/CSS → кадры через Chromium: заголовки, «таблетки», связи, камера |
| `colimator/compositor.py` | наезды и проезды по кадру, склейки, кроссфейд, смаз |
| `colimator/style.py` | палитра и метрики, снятые с референса |

Готовые сборки лежат в `scripts/`, каждая описана в `docs/`.

```bash
python3 scripts/build_agency_part1.py     # → out/agency_part1.mp4
```

## Как устроен ролик

Раскадровка — это список планов: с какой секунды по какую, откуда берутся
кадры, как по ним едет камера и каким переходом план входит. Графика — сцена
с узлами, у каждого своё время появления, и камерой, которая ездит по полотну.

Времена в раскадровке привязываются к границам фраз из субтитров, а не к
ровным секундам: тогда смена плана попадает в речь, а не разрезает её.

## Приёмы, до которых мы дошли

**Второй ракурс из одного плана.** Если материал снят одной камерой без
склеек, крупная рамка внутри того же кадра читается как отдельная камера.
Между такими планами можно резать, и стык не выглядит прыжком — этим же
прячется вырезание оговорок и пауз.

**Компоновка в Python, а не фильтрами ffmpeg.** `zoompan` считает рамку в
целых пикселях, и медленный наезд дёргается. Pillow умеет ресайз по дробной
рамке, поэтому движение гладкое. Время нигде не растягивается — звук остаётся
синхронным.

**Субтитры как якорь.** Они стоят в одной точке кадра поверх всего — и над
лицом, и над графикой. Именно это склеивает разнородные куски в один ролик.

## Съёмка

- Снимать в 4K: наезд до 2× тогда честный кроп без интерполяции.
- Оставлять запас над головой примерно в 1/6 кадра — иначе заголовку негде
  встать.
- Экспортировать **без вжатых субтитров**. Они раздуваются вместе с кадром на
  наездах и убираются только грязно.
- SRT отдавать отдельным файлом.
